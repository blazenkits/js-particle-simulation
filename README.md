# Powder simulation in Javascript

Client-side particle simulation in JS with oversimplified physics.
<br/>
<br/>
<br/>
- Inspired by The Powder Toy.
  
- Custom properties and physics for particles, defined in `particledata.js`

- Particle Interactions, pressure, etc.

Example: https://blazenkits.github.io/js-particle-simulation/

(simulates max 20000 particles)

<br/>
<br/>

### Note 2026-10-08 
I made this back in 2023, to learn how javascript works. It was my first project, back then there were no code agents, I didn't know much about algorithms, 
looking back this just renders everything sequentially on a canvas so frankly it is about the worst particle simulator implementation you can imagine.

I have no plans to update this when nowadays coding 'professionals' can prompt Claude Code and get a better quality simulator in, like, under 10 minutes. Though frankly that's what I'd probably do too.

Keeping this app public as a flashback to simpler (and buggier) times. Have fun!
